# 🎲 Virtual Dice Roller

A simple Python-based virtual dice roller that simulates rolling a real dice for board games, tabletop games, and fun experiments.

## 📌 Features

- 🎲 Roll a virtual six-sided dice (d6)
- 🔄 Roll again as many times as you want
- ⚡ Fast and lightweight command-line application
- 🎯 Generates random results using Python's `random` module

## 🖥️ Demo

Example:

```
🎲 Welcome to the Virtual Dice Roller!

Press Enter to roll the dice...

🎲 You rolled: 5

Roll again? (yes/no): yes

🎲 You rolled: 2

Roll again? (yes/no): no

Thanks for playing! 👋
```

## 🛠️ Technologies Used

- Python 3
- Random Module

## 🚀 How to Run

1. Clone this repository:

```bash
git clone https://github.com/your-username/Virtual-Dice-Roller.git
```

2. Navigate to the project folder:

```bash
cd Virtual-Dice-Roller
```

3. Run the program:

```bash
python dice_roller.py
```
